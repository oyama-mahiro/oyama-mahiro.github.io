# [Linux] 命令行与环境入门

这篇把早期的命令行笔记和后来的「系统基础」补记合成一篇。Shell 脚本和特殊符号放在《Shell 脚本》，`fork`、线程放在《进程与线程》。

## 1. 目录从根开始

Linux 没有 Windows 那种 C、D 盘。所有路径从根目录 `/` 出发。

| 目录 | 作用 |
|------|------|
| `/bin`、`/usr/bin` | 普通用户可执行程序 |
| `/sbin`、`/usr/sbin` | 系统管理命令 |
| `/etc` | 配置文件 |
| `/home` | 普通用户的家目录，`~` 表示当前用户的家目录 |
| `/dev` | 设备文件 |
| `/proc`、`/sys` | 内核导出的进程和设备信息，不是放在磁盘上的普通文件 |
| `/tmp` | 临时文件，重启后可能被清空 |
| `/var` | 日志、缓存等会变化的数据 |

绝对路径从 `/` 写起，例如 `/etc/passwd`。相对路径相对于当前目录，`.` 是当前目录，`..` 是上一级。

## 2. 每天会用到的命令

```text
pwd                 当前目录的绝对路径
ls                  列出非隐藏文件
ls -a               连隐藏文件一起列出
ls -l               长格式，能看到类型和权限
cd 路径             切换目录
cd                  回到家目录
clear               清屏，Ctrl+L 也可以
```

`ls -l` 第一列的第一位是类型：`-` 普通文件，`d` 目录，`l` 符号链接，`c` 字符设备，`b` 块设备，`p` 管道，`s` 套接字。后面九位是三组 `rwx`，分别对应用户本人、同组用户、其他人。`rw-r--r--` 写成数字是 `644`。

```text
chmod 644 文件
chmod -R 755 目录    递归修改目录里的内容
```

文件和目录：

```text
touch 文件           没有就创建，有就更新时间
mkdir 目录
mkdir -p a/b/c       连同中间目录一起创建
cp 源 目标
cp -r 目录 目标
mv 源 目标           改名或移动
rm 文件
rm -r 目录           删除非空目录，先看清楚再执行
rmdir 空目录
cat 文件
```

`rm -r` 不会进回收站。不要对 `/` 或不确认的目录使用。

查找和统计：

```text
grep 字符串 文件
grep -n 字符串 文件     带行号
grep -r 字符串 目录     在目录里递归找
find 目录 -name '*.c'
wc -l 文件              行数
```

`find` 按文件名找，`grep` 按文件内容找。

## 3. 链接、归档和压缩

硬链接和本体共用同一份数据，删掉其中一个名字，另一个还能读。软链接只是一条路径，本体移动或删除后，链接会失效。

```text
ln 文件 硬链接名
ln -s 文件 软链接名
```

不能给目录做硬链接。跨文件系统也不能做硬链接。

`gzip`、`bzip2`、`xz` 默认会替换原文件。打包目录用 `tar`，压缩和归档是两步，常用写法把它们写在一起：

```text
tar -czvf 包名.tar.gz 目录或文件    gzip
tar -cjvf 包名.tar.bz2 目录或文件   bzip2
tar -cJvf 包名.tar.xz 目录或文件    xz，J 是大写
tar -xvf 包名
```

`c` 创建，`x` 释放，`v` 列出过程，`f` 后面必须紧跟包名。`diff 文件1 文件2` 用来看两个文本文件差在哪。

## 4. 软件包、用户和网络

Debian、Ubuntu 用 `.deb`，离线安装用 `dpkg`，它不负责下载依赖：

```text
sudo dpkg -i 软件包.deb
sudo dpkg -r 软件名
```

在线安装用 `apt`。`apt-get` 还能用，日常安装、搜索、卸载用 `apt` 即可：

```text
sudo apt update
sudo apt install 软件名
sudo apt remove 软件名
```

用户：

```text
sudo adduser 用户名      会交互式设置密码和家目录
sudo deluser 用户名
passwd                   修改当前用户密码
su - 用户名              切换用户并加载对方的环境
```

不要手改 `/etc/passwd` 来删用户。平时用普通用户，需要管理员权限时在单条命令前加 `sudo`。`su` 不加 `-` 只换身份，不换家目录和环境变量。

看地址用 `ip`，不要再依赖已经从很多系统里拿掉的 `ifconfig`：

```text
ip addr
ping -c 4 地址
```

Windows 上对应的命令才是 `ipconfig`。虚拟机桥接、共享文件夹是 VirtualBox 或 VMware 的设置，路径常见是 `/mnt/hgfs`，以你安装的增强工具为准。

## 5. 进程命令

这些只是查看和结束进程。进程怎么创建，看《进程与线程》。

```text
ps aux              所有进程
pstree              树状关系
top                 按资源占用刷新，q 退出
kill PID            默认发送 SIGTERM，让进程自己退出
kill -9 PID         SIGKILL，强制结束，对方来不及清理
```

关机和重启：

```text
shutdown -h now
shutdown -r now
```

## 6. vim 和编译

`vim 文件` 打开文件，没有就创建。默认是普通模式，不能直接打字。

- `i`、`a`、`o` 进入插入模式，`Esc` 回到普通模式
- 普通模式里 `gg` 到文件头，`G` 到文件尾，`0` 行首，`$` 行尾
- `yy` 复制当前行，`dd` 剪切当前行，`p` 粘贴到下一行，`u` 撤销
- `ngg` 跳到第 n 行
- 输入 `:` 进入底行：`w` 保存，`q` 退出，`wq` 保存并退出，`q!` 不保存退出
- `/关键词` 向后查找，`n` 同方向继续，`N` 反方向
- `:%s/旧/新/g` 全文替换，加 `c` 则每次确认
- `gg=G` 按语法缩进全文；`:set number` 显示行号

```text
gcc 文件.c                 生成 a.out
gcc 文件.c -o 程序名
./程序名                   运行当前目录下的程序
```

当前目录默认不在命令搜索路径里，所以要写 `./`。

## 7. 终端快捷键

- `Ctrl+L` 清屏
- `Ctrl+C` 结束当前前台进程
- `Ctrl+Z` 暂停并放到后台，`fg` 可以拉回来
- `Tab` 补全命令和路径
- 上下方向键翻历史命令
